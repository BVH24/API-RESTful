# 📘 Notes API con Laravel

Una API REST sencilla para crear, listar, ver y eliminar notas, construida con Laravel.

---

## 🚀 Requisitos

- PHP >= 8.1
- Composer
- XAMPP o similar (para PHP CLI y base de datos SQLite)
- PowerShell (en Windows)

---

## ⚙️ Instalación

1. Clona o descarga el proyecto.
2. Abre una terminal en la raíz del proyecto.
3. Instala Laravel y dependencias:

```bash
composer create-project laravel/laravel notes-api "12.*"
